### 版本Java差异

1. Wing Kirin 附属模组从 1.21.1 NeoForge 分支移植到 1.20.1 Forge 分支（依赖 DragonSurvival 1.20.1-2.0.67）：技能 JSON 里的逐级数值字段（如 `"amount": {"type": "minecraft:linear", "base": ..., "per_level_above_first": ...}`）在 1.21.1 代码中用的是**原版** `net.minecraft.world.item.enchantment.LevelBasedValue`（1.21 新增，1.20.1 没有）；1.20.1 移植时应改用 DragonSurvival 自带的 `by.dragonsurvivalteam.dragonsurvival.common.codecs.LevelBasedValue`——`CODEC` 常量与 `calculate(int level)` 方法签名一致，JSON 格式完全相同，已注册的 `dragon_ability` 数据无需改动（2026-09 移植 `wing_kirin:damage_reflection` 时已验证）。

    **Why:** 两分支的技能效果代码大量使用 LevelBasedValue，不查清楚会导致 1.20.1 编译失败或误以为 JSON 不兼容。

    **How to apply:** 遇到 1.21.1 效果/技能代码引用 `net.minecraft.world.item.enchantment.LevelBasedValue` 时，直接把 import 换成 DS 的 `common.codecs.LevelBasedValue`，其余逻辑不动。相关：DS 1.20.1 的实体效果系统 `AbilityEntityEffect` 与 1.21.1 接口一致，可用同样方式移植（参考 [[ds-1201-entity-effect-system]]，若尚未记录可据此补写）。
