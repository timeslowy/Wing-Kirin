## 📖 简介

**翼麒麟（Wing-Kirin）** 是「[龙之生存](https://github.com/DragonSurvivalTeam/DragonSurvival)」的一个附属模组，为原版龙之生存增加了全新的种族、能力、以及与之配套的视觉效果与玩法机制。项目代码基于 **NeoForge 1.21.1**，主要编程语言为 **Java** 与 **mcfunction**。

此附属是龙之生存中国社区生长出的**第三个**附属模组，几乎开启了龙生附属中国社区的狂飙突进时代。

原来此仓库是私有仓库，但鉴于此模组的完善程度已极大，后续发展潜力几近榨干，因此我决定将所有文件公开，为后来者提供一个**可行的框架**。这一决定，也使得本模组成为**第一个公开源代码**的龙之生存附属。

这个模组是作者的第二个Minecraft模组（欢迎考古第一个：[「岩城乐事」](https://www.curseforge.com/minecraft/mc-mods/duacan-delight)），因而每个文件都有详尽的注释，方便理解逻辑。  

翼麒麟更新已进入瓶颈，今后只会在龙生本体版本升迁/重大API变动时才会更新。
